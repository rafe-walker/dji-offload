# Contributing

Issues and pull requests are welcome.

- Run `cargo test` and `cargo clippy -- -D warnings` before opening a PR.
- Test fixtures must use fictional APNs, addresses and coordinates.
- Every commit needs a Developer Certificate of Origin sign-off
  (`git commit -s`), certifying you wrote the change or have the right to
  submit it under the project license. See https://developercertificate.org/.
